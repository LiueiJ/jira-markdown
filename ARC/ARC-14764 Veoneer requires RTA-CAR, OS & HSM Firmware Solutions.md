# ARC-14764 Veoneer requires RTA-CAR, OS & HSM Firmware Solutions

> [!jira] New ·  · [[Buttle_Darren_(ETAS-ECMPRM1-EMW)|Buttle Darren (ETAS-ECM/PRM1-EMW)]] · 更新于 2026-08-11T15:37:17.000+0000
> [在 Jira 中打开](https://jira.etas-dev.com/browse/ARC-14764)

## 描述

**RTA-CAR SOW (BIP)** :

As part of the RTA Basic Integration Package, ETAS will provide the following:

- ​AUTOSAR Portable BIP:
  - Ported to the ​CHINA-CORE CCFC3008PCS/CCFC3008PCS_A microcontroller, supporting operation on a Customer ECU.
  - Compiled using the ​GHS compiler 1.4.
- ​Integrated Modules:
  - ​RTA-OS: Real-Time Operating System (RTAOS).
  - ​RTA-RTE: Runtime Environment.
  - ​RTA-BSW: Basic Software.
  - ​MCAL: Microcontroller Abstraction Layer, provided by China Core.
- ​Training Services:
  - ETAS will conduct a 3-day training session at ​Veoneer to familiarize the team with the ETAS toolchain and the BIP.

**Test Configuration of Delivered Modules**

The delivered modules will be provided in a test configuration, including:

- ​Sample Application Components: Example code to demonstrate functionality.
- ​Related BSW Configuration:
  - ​CAN TX/RX: Demonstrates CAN communication functionality.
  - ​UDS Diagnostics Processing: Demonstrates diagnostic functions based on the UDS protocol.
  - ​Non-Volatile Memory Access: Demonstrates read/write operations on non-volatile memory.

**HSM SOW :**

- ETAS provides a development version of the CycurHSM SDK development package for China Core FC3008ABS Chip HSM C
- ETAS provides 50 person days of service to support Veoneer building a HSM firmware for the China Core FC3008ABS by providing integration example code for porting CycurHSM SDK to FC3008ABS.
- ETAS provides technical support service to Veoneer for HSM package be integration at host side use cases implementation.
- ETAS provides a production package version of the **CycurHSM SDK for China Core FC3008ABS Chip HSM Core.**

**OS Porting** 

- Ported to the **​CHINA-CORE CCFC3008PCS/CCFC3008PCS_A** micro controller, supporting operation on a Customer ECU.
- Compiled using the ​GHS compiler 1.4.
