> As per the discussion, please find the summary of the discussion and action plan. 
> ----
> ## **"\.buildframework"** folder is not delivered to SCM (like GIT).
>
> **General Instruction:** When user store the generated output in SCM, then it is mandatory to deliver also the "\.buildframework" folder into SCM.
>
> {*}Action for Tools{*}: We will enhance User Guide with this instruction.
> ----
> ## **"\.settings\com.bosch.wbp.mdf.internal.register.PreferenceBasedMetadataStore.prefs"** 
>
> **-->** It is found that the file is either emptied or the path to EOC files are different to the one found in the project {_}(File path in prefs file: ecu_config/bsw/gen/bswmd/LinTrcv_EOC.arxml / Actual file path of EOC files: ecu_config/bsw/gen/LinTrcv_EOC.arxml){_}. due to which those EOC ARXML files were not loaded or visible in ISOLAR editors.
>
> **General Instruction:** It is generally not recommended to delete or move around the files which are generated by RTA Code Generators (RTA-BSW, RTA-RTE or RTA-OS). It is highly possible that these files would be regenerated when the code generator is executed again and would cause duplicated files for downstream tools.
>
> {*}Proposed solution{*}: Files available in the gen folder would be automatically considered for loading and visible in ISOLAR editors.  
>
> **Action for Tools:** Tools will backport the solution from 12.12.0 to 12.11.0 as a patch
>
> **Action for Customer / project team:**
>  # Avoid duplicating generated ARXML files into other location in the project.
>  # Compare `ecu_config\bsw\gen\WdgM_Cfg_EOC.arxml` and `ecu_config\bsw\gen\bswmd\WdgM_Cfg_EOC.arxml` and decide which was showing differences in content
>
> ----
> ## **output\bsw\rba_CryptoAuHSM3\integration\rba_CryptoAuHSM3_KeyServices_EcucValues.arxml**
>
>  **-->** It is observed that the value of one of the parameters in this ARXML file needs to be modified for project demand. To achieve this, user was moving this file to different location within project and controlling the content. However, this is not expected approach as Tool would regenerate this file every time RTA Code Generator is executed which would lead to duplicate value for the same parameter. **
>
> **General Instruction:** Integration files are allowed to be modified by user for their project demand. Tool will retain the modification upon regeneration as well.
>
> **Action for Customer / project team:** Directly modify the Integration files within the output folder, do not delete generated files / folders.
