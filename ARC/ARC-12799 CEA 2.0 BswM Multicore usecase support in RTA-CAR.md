# ARC-12799 CEA 2.0 BswM Multicore usecase support in RTA-CAR

> [!jira] Analyzed · Medium · [[Jain_Vihitha_(MSEMS-ETAS)|Jain Vihitha (MS/EMS-ETAS)]] · 更新于 2026-02-24T07:25:02.000+0000

## 描述

The **background** is that during the discussion on Multi-Core Use Case for Cariad, customer considered our current implementation of BswM model for Multi-Core is not the State of Art – **Only one instance of BswM without multi-partition instance support**.

As the diagram shown below, this is somehow the current multi-core distribution plan from customer.

Since we only have one instance of BswM, the action control for example BswMLinScheduleSwitch shall be called cross core, which needs EA protection with SpinLock if the action is triggered by BswM_MainFunction.

With the experience of CEA1.0, **customer thinks**  frequently switching LIN schedule table will block functions in different cores.

**Customer Expectation**

Support BswM multi-partition instances.
