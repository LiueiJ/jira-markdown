## 描述

The requirement aims to have features into the core product to replace functionalities currently implemented in the COBRA framework.

In addition, the solution should enable a flexible customization allowing users to extend or tailor functionality through scripts on top of the core product. This scripting mechanism should maintain separation between core logic and user-defined extensions to ensure maintainability, scalability, and ease of updates.

### **Objectives:**

- Replace COBRA-scripts with equivalent or improved core product features.

- Establish a robust scripting interface to allow controlled customization and configuration beyond core capabilities.

- Ensure backward compatibility and support to execute COBRA scripts in new versions of product without change
