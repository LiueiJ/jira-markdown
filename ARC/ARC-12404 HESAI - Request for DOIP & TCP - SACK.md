# ARC-12404 HESAI - Request for DOIP  & TCP - SACK

> [!jira] New ·  ·  · 更新于 2026-05-11T20:50:32.000+0000
> [在 Jira 中打开](https://jira.etas-dev.com/browse/ARC-12404)

## 描述

HESAI is currently in an acquisition of an OEM project ( presently Hesai would not reveal the OEM ). But there are 3 clear requirements that HESAI would like our product to support .

1. DOIP Payload type: Currently, our tool only support 8001 payload type; customer needs to support 0000， 8001，8002 & 8003 types.

2. TCP can support SACK(selective acknowledgement) and congestion control

3. Improved ICMP  errors responses.

More details are in the needs ticket : [ARC-12251](https://jira.etas-dev.com/browse/ARC-12251)
