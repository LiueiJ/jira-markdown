1. BSW Code Generation was successful
2. I changed some config
3. BSW Code Generation fails with errors relating to not being about to find *output files*

Why should a user care whether ISOLAR cannot find an *output file*? The only thing that should effect code generation is input arxml. 

I recognise that detection of what output files exist and what their current state is part of the incremental code generation, but a failure in this system should simply have a fall back mechanism of "If I can't determine what had been generated last time, I should generate everything"
