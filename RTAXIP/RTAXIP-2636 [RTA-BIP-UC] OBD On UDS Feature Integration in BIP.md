## 描述

Motivation:

OBDonUDS - SAE J1979-2 is the new diagnostic standard for vehicle diagnostics that replaces the older OBD-II protocol, offering features like more detailed fault codes, improved repair times, and enhanced data capture. It is based on the UDS (Unified Diagnostic Services) standard and provides a more robust and flexible framework for communication between vehicle diagnostic tools and the vehicle's electronic control units (ECUs). And more and more customer will apply this feature to their SW

Bip lack this feature. Do we implementation this feature for BIP?
