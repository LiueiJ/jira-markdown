> [!jira] Closed · High ·  · 更新于 2026-03-23T04:38:10.000+0000

## 描述

#### 1. **Motivation**

- **Context**: DET module help developer to avoid error during development phase and Developer should take care to check these DET errors.
- **Problem**:
  - BIP is missing guideline to give awareness to developer for checking.
  - Error justification is missed which make user confuse with these errors
- **Impact**:
  - **Developers:** This helps developer to avoid development/configuration error during development phase.
- **Urgency**: This is small task but there is huge benefit for developers.

#### 2. **Proposed Change**

- Update document to guide developer check DET errors
- Justification for any existed DET error
- Add Test case to test it
