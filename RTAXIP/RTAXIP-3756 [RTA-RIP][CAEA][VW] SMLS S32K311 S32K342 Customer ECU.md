## 描述

Customer project for Volkswagen, led by Zhejiang Changjiang Automotive Electronics (CAEA), to source and integrate a protocol stack for the SMLS steering column switch.

The project requires a production-ready Classic AUTOSAR-based solution on NXP S32K311/S32K342, covering CAN/CAN FD communication, diagnostics, bootloader, and related integration support for future vehicle launch.
